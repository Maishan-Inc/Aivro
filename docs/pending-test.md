## 本轮：高危漏洞复核后的补充修复

以下改动尚未运行语法检查、类型检查、测试、构建或部署；依赖安装与 OSV 公告查询不替代实际验证。

- 依赖：Next 16.4.5、Sharp 0.35.5、Axios 1.21.0、Nanoid 5.1.16；更新受影响的前端间接依赖，删除仅为 CSS 引入的 shadcn CLI，保留实际使用的下拉框状态样式。Go 更新 Gin、以太坊签名依赖、pgx、QUIC、压缩及相关依赖。按锁文件安装后验证三种数据库、MetaMask、上传、下载、各工作台和容器启动；`/_next/image` 返回 404。
- 分享：至少 8 字符且包含字母与数字的密码可保存，弱密码被拒绝。先取得访问凭证，再修改密码或更新分享版本，旧凭证不能再预览或 Fork；新验证可正常访问。用户名路径与 token 路径行为一致。并发撤销/改密与复制时事务不越过当前分享状态和版本，失败不扣工作流额度。
- 登录限制：匿名访问 `/api/prompts`、`/api/assets` 时，开启对应开关后拒绝返回数据，失效会话同样拒绝；有效会话与管理员列表正常。先填充提示词数据缓存，再打开登录限制，匿名请求仍拒绝；直接请求 Go 与经过 Next 的结果一致，成功和失败响应均不公开缓存。
- 页面 CSP：不同语言首页与其他 HTML 返回 `no-store`，逐请求脚本 nonce 与响应策略一致，不复用上一次请求的 nonce；静态文件与演示图缓存正常。上线入口清除旧缓存，不覆盖应用的 `no-store`。
- CAPTCHA：hCaptcha 必须使用后台配置的 sitekey，其他 sitekey 的票据失败；Turnstile 返回的 hostname 必须匹配 APP_ORIGIN 或明确允许的来源。错误、过期、重复 token、缺少配置、非 200 响应、超时均拒绝。hCaptcha 不把浏览器提供的 hostname 当作鉴权依据。验证合法登录、注册、MetaMask 和分享密码流程及六语言提示。
- 管理员：新数据库使用空密码或两个公开默认密码时拒绝初始化，更换用户名不能绕过；独立强密码可创建。已有管理员的重启不自动改密，默认密码登录及后台设置默认密码被拒绝。
- 素材导入：ZIP 上限 128 MiB，单文件解压上限 64 MiB，总解压上限 256 MiB，最多 512 个 ZIP 条目、500 个素材及 500 个文件，`assets.json` 上限 4 MiB；上传最多并行 3 个，仍受后端单次上传 50 MiB 和账号配额限制。超限、重复/穿越路径、缺文件、错误结构、MIME/大小不一致和未引用的清单文件在上传前拒绝。检查同一文件被多个素材引用时正常导出/导入；JavaScript 地址不能作为媒体下载地址，封面只保留 HTTP/HTTPS 或受限 PNG/JPEG/WebP/GIF data 预览，六语言错误提示和再次选文件正常。
