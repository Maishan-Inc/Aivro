## 系统漏洞与 BUG 修复待验证

本轮仅完成代码修改与阅读复核，按项目约定未运行语法检查、编译、构建或测试。以下均需人工验证：

- 模型权限与计费配置：直接请求隐藏模型、错误服务范围、无价格模型应失败且不调用上游；新增公开模型不应被自动配置为 0 点，显式设为 0 点可免费调用。图片 JSON/multipart 的空、重复、负数、小数、超大 `n` 应拒绝，正常 1–10 张按数量扣费。
- OAuth 账户隔离：未验证邮箱不用于关联；第三方 ID 首次登录但邮箱已属于现有账号时应拒绝合并。GitHub 仅接受 verified 邮箱；原第三方账号登录仍正常。
- 并发账户更新：登录、头像和资料保存与扣费、密码重置、封禁并发时，不应覆盖余额、密码或状态；重置密码递增 token version。后台调整余额和 AI 扣费/退款与对应流水应一起成功或回滚。
- Stripe：未付款的 completed 不发放权益；paid completed/async_payment_succeeded 正常发放；重复或并发回调仅发放一次，金额、币种、用户、套餐和 session 不匹配均拒绝。Checkout 创建失败后可再次创建，不因唯一空 session 冲突；多套密钥请求不交叉使用全局密钥。
- Didit：同会话并发 approved 只奖励一次；启用 RewardOnce 时，不同会话、状态回退后再 approved 也不能重复奖励。奖励与同时发生的 AI 扣费均保留；超大 webhook 在签名验证前拒绝。
- 视频任务：使用其他用户的本站任务 ID 或任意上游 ID 查询/下载应失败；同模型多个渠道时仍使用创建渠道，原渠道关闭或密钥变更后返回不可用。
- 文件共享与生命周期：两份工作流、分享快照、社区快照、生成历史和素材引用同一文件时，删除其中一项不影响其他项。撤销分享、删除社区作品及源工作流会释放各自引用，已复制工作流仍可读取和保存文件；联动更新只修改尚存在且仍联动的副本。
- 历史与素材：保存素材成功后再删除生成历史或触发到期清理，素材文件仍可读取；最后一个引用释放后才删除文件。历史与引用在同一事务保存，数据库读取失败不得当作“空历史”删除；历史展示的媒体期限与历史自身一致。
- 文件并发：保存引用与自动清理并发时，不应出现已成功保留却被删除的文件；上游下载解析到私网、回环或 DNS 重绑定地址时应拒绝。本地、S3/R2 分别确认存储删除失败的错误反馈。
- 本地账户隔离：A/B 账号和访客各自读取 localforage 素材列表，切换后立即清空旧列表；旧异步请求不得覆盖新账户列表或画布。连续新增/编辑/删除按序保存，后端保留失败不显示成功。此变更不是本地素材列表云同步，也未迁移旧全局素材桶。
- 画布自动保存：空闲不应持续请求更新；拖动、缩放、节点修改在 600ms 防抖后有序保存，慢请求不覆盖新界面；切换项目、账户或 Agent 预览后不应用旧响应。
- Ask/直接聊天/Agent：固定计费与 token 计费分别确认；JSON 与 SSE usage 正确结算，缺少 usage 的估算不超过预扣，失败退款；输入超限、非布尔 stream、非法 n 和输出上限应拒绝。流式已输出后出现错误时保留已发生用量，不再混入业务 JSON。
- 3D：无渠道、上游失败或没有真实模型文件时不能返回收费成功；正常结果仍保存模型及生成历史。
- 队列：上游或对象读取卡住时在执行期限内失败；重启只回收过期租约，不误退其他实例活跃任务；同时取消/执行/重复恢复最多退款一次，终态失败不能把已退费任务改回成功。该项不代表已实现多实例严格共享限流。
- 限流与缓存：伪造 Forwarded、X-Forwarded-For、X-Real-IP、CF-Connecting-IP 或内部 IP 头不能绕过限流；配置可信入口后验证真实 IP，未配置时使用未知 IP 的共享限制及账号限制。分享密码连续错误触发限制；提示词缓存最多 128 个查询，限流桶最多 10000 个且过期清理。
