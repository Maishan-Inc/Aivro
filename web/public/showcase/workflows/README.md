# 首页工作流演示素材

- `product-*`：琥珀色香水瓶，原图与日光广告、暗调水景广告。
- `anime-*`：薄荷绿短发信使，角色设定与树脂手办棚拍、收藏柜展示。
- `game-*`：青铜星月提灯，道具概念与材质渲染、森林遗迹场景。
- `cinema-*`：峡谷基地，同一建筑布局和机位的日景、夜景、沙尘黄昏。

上述 12 张图片使用用户提供的兼容图片接口及 `gpt-image-2.5-flare` 生成；每组后两张通过编辑本组参考图获得。网页使用压缩 WebP，原始图片与生成提示词在工作区 `output/imagegen/` 中。不在素材或前端代码中保存 API 密钥。

`video-reference.webp` 和 `video-ending.webp` 分别取自演示片段第 1 秒与第 6 秒。视频是开放授权的流程示例素材，不是 Aivro 本次生成的结果。
